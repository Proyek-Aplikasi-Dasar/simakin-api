MAJOR CHANGES
================================================================================

🔥 Perubahan Requirement #1: HAPUS APPROVAL JURNAL

   Before:
   - Siswa input → Guru approve/revise → Lock jurnal
   - Endpoint: PUT /api/jurnal/{id}/approve, /api/jurnal/{id}/revise
   - Field: status_review, catatan_guru, reviewed_by, reviewed_at, is_editable
   
   After:
   - Siswa input → Bisa edit kapan saja
   - Admin bisa edit semua jurnal
   - Guru hanya view (read-only)
   - Field: edited_by, edited_at (tracking saja)
   
   Impact:
   - Hapus 2 endpoint
   - Hapus 5 field database
   - Hemat 1 hari Sprint 5 (dari 5 → 4 hari)

🔥 Perubahan Requirement #2: METADATA GPS + TOKEN VERIFIKASI

   Tambah di penilaian_bulanan:
   - verifikasi_waktu (timestamp)
   - jarak_dari_pkl (decimal, Haversine calculation)
   - dalam_radius (boolean flag)
   - token_verifikasi (varchar 6 digit, UNIQUE)
   - token_generated_at (timestamp)
   - token_used_at (timestamp)
   
   Tambah di perusahaan:
   - radius_presensi (int, default 100 meter)
   - pembimbing_industri (varchar)
   - bidang_usaha (varchar)
   
   Impact:
   - Tambah 1 endpoint: POST /api/penilaian/{id}/generate-token
   - Update endpoint: POST /api/penilaian/{id}/verifikasi (validasi token + GPS)
   - Implementasi Haversine formula
   - Tambah 1 hari Sprint 6 (dari 5 → 6 hari)

❓ Decision #1: Approval Jurnal - HAPUS atau KEEP?
   Rekomendasi: HAPUS (sesuai mockup)
   Alasan:
   - Mockup mobile tidak ada status review
   - Mockup web admin ada tombol "Edit" bukan approve/reject
   - Workflow lebih sederhana
   
   Jika KEEP:
   - Tambah 2 endpoint + 5 field
   - Tambah 1 hari Sprint 5
   - Mockup perlu revisi
   
   ➡️ Mohon konfirmasi dari PM & UI/UX

❓ Decision #2: Token Verifikasi - WAJIB atau OPSIONAL?
   Rekomendasi: OPSIONAL (dengan fallback)
   Alasan:
   - Mockup jelas menunjukkan input token
   - Pengiriman token ke pembimbing industri di luar sistem (manual)
   - Bisa jadi blocker jika pembimbing tidak dapat dihubungi
   
   Proposal:
   - Implementasi penuh (generate + validasi)
   - Admin bisa bypass token jika ada kendala
   
   ➡️ Mohon konfirmasi dari PM & UI/UX
